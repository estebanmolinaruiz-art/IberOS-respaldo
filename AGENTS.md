# Reglas obligatorias del respaldo IberOS

**Presupuesto: coste adicional 0 €**. No efectuar pagos, contratar hosting, comprar créditos, recargar carteras, utilizar APIs o herramientas facturables ni autorizar ampliación de cuota. Todo flujo de copia y publicación debe mantenerse dentro del plan gratuito de GitHub para repositorios públicos; detenerlo si no puede verificarse que es gratuito.

La copia independiente de IberOS no debe perderse, redirigirse al dominio principal ni modificarse sin verificaciones. No guardar secretos en el repositorio. El dominio existente puede exigir una renovación futura de pago: no activarla automáticamente.
